# miniGit

Groupe gestionnaire de version automatisé : HAMMOUCHE Sami, BOUKHLLIA Elias, HAMARA Camara, AZEDDIN Bilail

## Description

Un programme en Python qui surveille un dossier et sauvegarde automatiquement ses versions quand il est modifié. On peut ensuite voir l'historique des versions et en restaurer une. Le tout se fait depuis une petite interface web en local.
